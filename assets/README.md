# Assets Directory

This directory should contain the following image assets for the Reflectify app:

## Required Assets

### App Icons
- `icon.png` - 1024x1024px app icon
- `adaptive-icon.png` - 1024x1024px adaptive icon for Android
- `favicon.png` - 16x16px or 32x32px favicon for web

### Splash Screen
- `splash.png` - 2048x2048px splash screen image

### Notifications
- `notification-icon.png` - 96x96px notification icon (Android)

## Design Guidelines

- Use a minimalist design with the color palette:
  - White (#ffffff) - 70%
  - Black (#1a1a1a) - 20%
  - Gold (#d4af37) - 10%
- The icon should feature a simple, recognizable symbol (e.g., a leaf, crescent moon, or book)
- Keep designs clean and professional

## Temporary Assets

For development, you can use placeholder images. The app will work with default Expo assets until you replace them with custom designs.

To generate icons quickly, you can use:
- https://www.appicon.co/
- https://icon.kitchen/
- Design your own in Figma or Adobe XD
