# Quiz Sound Effects

Place your sound files in this directory with the following names:

- `correct.mp3` - Plays when user answers correctly
- `wrong.mp3` - Plays when user answers incorrectly
- `complete.mp3` - Plays when quiz is completed
- `tick.mp3` - (Optional) Timer tick sound

## Supported Formats
- MP3
- WAV
- M4A
- AAC

## Recommended Specifications
- Short duration (0.5-2 seconds)
- Small file size (< 100KB recommended)
- Sample rate: 44.1kHz or 48kHz
- Bitrate: 128kbps or higher for MP3

## Adding Your Sounds
1. Place your sound files in this directory
2. Make sure the filenames match exactly (case-sensitive)
3. The app will automatically load and use them
